# 上下文地图

当前 DSH 在聊天右侧显示可调整宽度的上下文面板，默认 340px，正常范围 240–640px。拖动左边缘调整，向右拖至不足 150px 后松手可收起。顶部“上下文”按钮切换开关，面板内 × 也可关闭。宽度与开关状态保存在当前浏览器 localStorage；收起会释放聊天预留空间。窄屏打开时以覆盖面板显示，不压缩聊天。另保留“上下文”页签供完整查看。此目录已作为 @local/dsh-context-map 安装并启用于 desktop profile。

分隔边缘支持键盘左右键调整（每次 20px）、Home/End 设最小/最大、Esc 收起。

地图继承 DSH 当前主题，不再覆盖全局背景。全局配色由独立的 [外观 · Orca 暗色](../dsh-theme-orca/) 插件管理，可分别安装与启停。分类固定使用灰色 Prompt、天蓝用户消息、绿色 Tool、橙色 Memory。

这是一版 A 方案试用：上下文组件挂在现有 Session 槽位，通过 CSS 在聊天右侧预留空间并固定显示；并未替换原页头或聊天输入组件。打开原生右侧工具栏时可能争用右侧区域，需要后续视觉调整。

## 使用

- 每个格子代表 1,000 个估算 token，按输入上下文顺序连续排列。
- Prompt：系统与开发者指令；Tool：工具定义、调用与结果；Memory：compact-checkpoint 压缩摘要；另有用户消息和助手历史。
- 混合格用各类占比渐变显示；悬停或键盘聚焦显示 token 范围、分类数量及最多三条消息的短预览。
- 点击格子打开消息详情浮层，列出格子涉及的各条完整消息；同一条消息跨分类时去重。工具定义格显示工具 schema，空闲格显示无消息提示。
- 点击浮层外空白、关闭按钮或按 Esc 关闭；文本可选择复制。读取复用当前 session 的按序号历史加载接口，首次加载较早消息时可能稍有等待。
- 用下拉框或前后按钮切换已记录的模型尝试，默认跟随最新。
- 日志提供 contextWindow 时补齐空闲格；没有容量时只显示占用部分。
- 每次 assistant/message 或 assistant/attempt 结算时，在加入本次输出之前冻结输入。当前未结算步骤仅提示等待。

## 数据与局限

使用 Host sessionProjections 增量折叠已有日志，不注入模型上下文。投影仅保存序号、分类、估算值和请求元信息；悬停或点击时从当前 session 的原始历史中按需读取消息正文，不在投影重复缓存正文。最近 256 次尝试可切换；超出时显示截断数量。消息详情展示日志消息的完整内容，不声称是 token 区间的精确文本切片或模型适配器的最终传输字节。

分类占用使用当前 tokenMeter.estimateMessage 的启发式估算，工具定义按 JSON 长度 / 4 计价。图片和附件没有使用模型专属视觉定价。模型报告的 inputTokens 单独显示，不按比例伪造各类精确计费。

Memory 特指已落盘的压缩摘要。技能、文件和普通工具返回按其日志角色分类，不根据文本猜测“记忆”。

目录链接插件无法直接解析安装目录中的 @deepseek-ai/dsh-session，故 index.js 内包含已核实的少量 surface 消息提取规则。升级 DSH 后需核对 Session 事件契约。
