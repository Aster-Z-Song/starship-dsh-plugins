# 外观 · Orca 暗色

包名：`@local/dsh-theme-orca`。

独立管理 DSH 的全局背景、边框、文字与侧栏配色。从上下文地图提取，启用后跨页面生效；禁用后撤销自己的覆盖层并恢复底层主题。打开或关闭上下文地图不会控制此插件。

在插件管理中搜索“外观 · Orca 暗色”即可单独启停。沿用原上下文地图的配色，浅色/深色偏好均显示这套暗色外观，不改写原主题偏好。

Host 端无服务和事件注册；主题覆盖仅在 Client 端运行，清理由插件生命周期管理。

| 区域 | 色值 |
| --- | --- |
| 基础背景 | #0a0d12 |
| 一级背景 / 侧栏 | #0f131c |
| 二级背景 | #161d2b |
| 浮层 | #1e2636 |
| 一级 / 二级边框 | #2a3241 / #3a4454 |
| 主要 / 次要文字 | #eee9f6 / #c1b5ce |

变更目的、过程与验证结果见 [CHANGELOG.md](CHANGELOG.md)。
